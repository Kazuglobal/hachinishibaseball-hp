# 野球ミニゲーム 要件定義書

## 1. プロジェクト概要

### 1.1 背景
八戸西高校野球部OB会の公式サイトにおいて、訪問者のエンゲージメント向上とサイト滞在時間の増加を目的として、野球テーマのミニゲームをメニューに追加する。

### 1.2 サイトの目的・ターゲット
| 項目 | 内容 |
|------|------|
| サイト目的 | 野球部への支援促進、OB会員の絆強化、現役選手への応援 |
| ターゲット | OB会員（卒業生）、現役選手の保護者、野球部を応援する地域住民 |
| 年齢層 | 30代〜60代が中心、10代〜20代も含む |
| デバイス | スマートフォン・タブレット・PC |

### 1.3 成功指標（KPI）
- ゲームプレイ率：訪問者の20%以上がゲームをプレイ
- 平均プレイ時間：1回あたり2分以上
- リプレイ率：50%以上が複数回プレイ
- SNSシェア率：プレイヤーの10%以上がスコアをシェア

## 2. ゲームコンセプト選定

### 2.1 候補ゲーム比較

| ゲーム種別 | メリット | デメリット | 開発難易度 | 推奨度 |
|-----------|---------|-----------|-----------|--------|
| **ホームランダービー** | 直感的操作、爽快感、短時間で楽しめる | 単調になりやすい | ★★☆ | ◎ |
| ピッチングゲーム | 野球らしさ、技術要素 | UI設計が複雑 | ★★★ | ○ |
| バッティングセンター | シンプル、馴染みやすい | 類似ゲーム多数 | ★★☆ | ○ |
| 野球クイズ | 教育的、OB情報活用可能 | ゲーム性が低い | ★☆☆ | △ |
| 打順シミュレーション | 戦略性、チーム愛醸成 | 理解に時間必要 | ★★★ | △ |

### 2.2 選定：ホームランダービー
**理由:**
1. **直感的な操作** - タップ/クリックのみで遊べ、幅広い年齢層が楽しめる
2. **野球の象徴的瞬間** - ホームランは野球の最も盛り上がる場面
3. **短時間で完結** - 1ゲーム1〜2分で完結し、カジュアルプレイに最適
4. **スコア競争** - ランキング機能でリピート動機を創出
5. **八戸西らしさ** - 学校カラーや野球部の要素を視覚的に表現可能

## 3. ゲーム仕様

### 3.1 ゲーム名
**「ハチニシ・ホームランダービー」**
（英語: Hachinishi Home Run Derby）

### 3.2 ゲームルール

#### 基本ルール
- 制限時間：60秒
- 投球数：無制限（時間内）
- 目標：できるだけ多くのホームランを打つ

#### スコアリング
| 打球結果 | ポイント | 演出 |
|---------|---------|------|
| ホームラン（センター方向） | 100点 | 花火エフェクト |
| ホームラン（左右方向） | 80点 | 標準エフェクト |
| 二塁打/三塁打 | 30点 | ヒットエフェクト |
| 単打 | 10点 | 軽微なエフェクト |
| ファウル | 0点 | なし |
| 空振り | -5点 | なし |

#### コンボシステム
- 連続ホームラン：×1.5倍ボーナス
- 5連続以上：×2.0倍ボーナス
- 10連続以上：×3.0倍ボーナス + 「フィーバーモード」突入

### 3.3 操作方法

#### タイミングベースシステム
```
[投球] → [スイングゲージ表示] → [タップ/クリック] → [結果判定]

タイミング判定:
- Perfect (±50ms): ホームラン確定
- Great (±100ms): 長打〜ホームラン
- Good (±150ms): 単打〜長打
- Miss (±200ms以上): 空振りまたはファウル
```

#### デバイス別操作
| デバイス | 操作方法 |
|---------|---------|
| スマートフォン/タブレット | 画面タップ |
| PC | マウスクリック または スペースキー |

### 3.4 難易度設定

| レベル | 球速 | タイミング許容範囲 | 対象 |
|-------|------|-------------------|------|
| イージー | 遅い（120km/h相当） | ±200ms | 初心者・年配者 |
| ノーマル | 普通（140km/h相当） | ±150ms | 一般プレイヤー |
| ハード | 速い（160km/h相当） | ±100ms | 上級者 |
| レジェンド | 超高速（180km/h相当） | ±80ms | チャレンジャー |

## 6. 技術要件

### 6.1 技術スタック

| レイヤー | 技術 | 理由 |
|---------|------|------|
| フレームワーク | Angular 20 | 既存サイトとの統一 |
| スタイリング | Tailwind CSS | 既存サイトとの統一 |
| アニメーション | CSS Animations + requestAnimationFrame | 軽量・高パフォーマンス |
| 音声 | Web Audio API | ブラウザネイティブ |
| データ保存 | localStorage | サーバーレス、シンプル |

### 6.2 パフォーマンス要件

| 指標 | 目標値 | 測定方法 |
|------|--------|---------|
| フレームレート | 60fps維持 | Chrome DevTools |
| 入力遅延 | 16ms以下 | Performance API |
| 初回ロード | 2秒以下 | Lighthouse |
| メモリ使用量 | 50MB以下 | Chrome DevTools |

### 6.3 ブラウザサポート

| ブラウザ | 最小バージョン |
|---------|--------------|
| Chrome | 90+ |
| Safari | 14+ |
| Firefox | 88+ |
| Edge | 90+ |
| Safari iOS | 14+ |
| Chrome Android | 90+ |

### 6.4 アクセシビリティ

- キーボード操作対応（スペースキーでスイング）
- 適切なコントラスト比（WCAG 2.1 AA準拠）
- 音声なしでもプレイ可能（視覚的フィードバック）
- Reduced Motion対応（アニメーション簡略化オプション）

## 付録A: 競合分析

### 参考ゲーム
1. **MLB Home Run Derby 2024** - 公式アプリ、高品質だが重い
2. **Baseball 9** - カジュアルゲーム、簡単操作
3. **プロ野球スピリッツA** - 本格派、操作複雑

### 差別化ポイント
- 八戸西高校の独自性（カラー、モチーフ）
- ブラウザで即プレイ可能（インストール不要）
- シンプルで誰でも楽しめる

---

## 付録B: ユーザーストーリー

1. **OB会員として**、空いた時間に気軽にゲームを楽しみ、母校への懐かしさを感じたい
2. **保護者として**、子供と一緒に野球部のサイトでゲームを楽しみたい
3. **現役部員として**、自分の学校のゲームを友達にシェアして自慢したい
4. **初回訪問者として**、ゲームをきっかけにサイトの他のコンテンツにも興味を持ちたい
